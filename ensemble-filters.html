Ensemble Kalman filters for CFD parameter estimation

Data assimilation combines a numerical model with observations to improve predictions by checking model accuracy and reducing uncertainty. I implemented the Ensemble Kalman Filter (EnKF) and its localized variant, the LETKF, in C++, and used both to recover an unknown source-term coefficient in a 1D convection–diffusion–reaction problem from sparse, noisy measurements.

C++EnKFLETKFFinite differences Runge–KuttaUVA CFD & Propulsion Lab

Test problem

A 1D convection–diffusion–reaction equation on 0 ≤ x ≤ 1 and 0 ≤ t ≤ 0.25, with a = μ = 1:

Governing equation∂φ/∂t + a ∂φ/∂x − μ ∂²φ/∂x² + βφ = f,   φexact = x²e−t

The reaction coefficient β (true value 1) is appended to the state vector and estimated by the filter, starting from an ensemble of perturbed β values with mean 8 and variance 5.

Solver

I programmed a finite difference solver in C++:

  • Space: 128 cells, fourth-order finite differences with forward-biased, central, and backward-biased stencils.
  • Time: fourth-order Runge–Kutta, Δt = 1×10−5 (25,000 steps).
  • Boundaries: Dirichlet left, Neumann right.
EnKF workflow. Each ensemble member is forecast with the numerical model. When observations are available, the innovation between observed and forecast values is weighted by the Kalman gain to form the analysis ensemble, which reinitializes the next forecast.

Methods

Two filters from the same family: one global, one local.

EnKF: global analysis

The ensemble spread is a Monte Carlo estimate of the forecast error covariance, so the full covariance never has to be propagated.

Kalman gainK = PfHT (R + H Pf HT)−1
Analysis updateQa = Qf + K (O − ℋ(Qf))

LETKF: local analysis

At each grid point, a Gaspari–Cohn taper weights nearby observations and the update is solved in the small ensemble space, so it scales to large CFD states.

Mean weightsw̄a = P̃a (Yb)T R−1 (yo − ȳb)
Member updatexna = x̄b + Xb (w̄a + [Wa]n)

Results

True β = 1, initial ensemble mean β = 8.

EnKF convergence. Ensemble mean β̄ for σobs = 0.04 and κ = 5, 10, 15. All runs converge from 8 to the true value of 1 (dashed).
Recovered state φ. Final φ(x) from each run overlays the true solution (β = 1). The grey curve is the model with the initial guess β = 8.
EnKF observation placement. Observations on one half of the domain (A or B) or both change convergence speed and overshoot.
LETKF localization radius. β̄ for four Gaspari–Cohn radii r. Narrow radii settle below the true value; r = 0.5 converges near β = 1.

Findings

  • EnKF recovered the unknown parameter. Every case converged close to β = 1 from a guess 8× too large, using sparse, noisy observations.
  • More frequent assimilation helps. Smaller κ generally converged faster and more accurately; however, additional assimilation steps are costly.
  • Observation placement matters. Convergence was faster with observations in the more sensitive region (right half), where the solution changes most rapidly.
  • LETKF accuracy depends on localization. Too narrow a radius starves each local analysis of observations.
