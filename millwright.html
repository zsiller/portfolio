Millwright: an AI agent as a second engineer

An in-development parametric CAD platform built around an agent harness, so an AI agent can work as a second engineer. The core is a B-Rep feature-tree modeler (CadQuery / OpenCASCADE) with integrated FEA and CFD for design verification and optimization.

Architecture

Agent harness

The agent works through the same tools and feature-tree operations as the UI, allowing the engineer and agent to exchange inputs seamlessly mid-design. Every agent action is parametric, visible in the tree, and undoable.

It can also search a local store of ingested engineering and tool documentation.

Modeling demo

From one prompt of named parameters and requirements, with no modeling steps, the agent built a hybrid motor forward bulkhead and injector as a parametric feature tree.

  • Stepped O-ring glands sized for a 3.53 mm AS568 O-ring.
  • Eight radial M5 bolt holes placed forward of both seals.
  • Feed path from a 1/4″ NPT port to a showerhead injector.
  • Result: one watertight B-Rep solid, 536 g in aluminum, with every dimension exposed as a named parameter.
